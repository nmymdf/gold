# 黃金價格走勢

*作者：ArchieKUO　專為 林葉玉 設計*

臺灣黃金存摺（每公克）與銀樓牌價（每錢）的每日走勢網頁，Windows 和手機都能用，可以「加到主畫面」當 App 使用。

## 功能

- 最新牌價與漲跌（與前一筆比較）
- 走勢圖：7 天／1 月／3 月／1 年／全部，可切換「每錢」或「每公克」
- 歷史明細表：日期、時段、時間、賣出、買進、漲跌
- 買賣簡易計算機：輸入重量或金額，比較銀行與銀樓哪裡比較划算，另附損益試算
- 下載 CSV 原始資料

## 資料更新時間（台灣時間）

| 資料 | 取價規則 | 單位 |
|---|---|---|
| 台銀黃金存摺 | **開盤**＝當日第一筆掛牌；**中午**＝12:00 前最後一筆；**收盤**＝15:30 前最後一筆 | 每公克 |
| 銀樓牌價 | 每日上午約 10:00 公告一次（週一～六） | 每錢 |

排程（台灣時間）：週一～五 09:05、12:15、15:45、21:05（補抓）；週一～六 10:15、10:40（銀樓）。GitHub 排程常會晚 5～15 分鐘。
網頁在打開、從背景切回來、或按「↻ 重新整理」時會讀取最新資料。
因為來源頁面列出當天每一次變價的掛牌時間，就算排程延遲，記錄到的仍是正確時點的價格。

### 資料來源

- 臺灣銀行官網（rate.bot.com.tw）有反機器人驗證，雲端主機無法直接讀取，
  因此台銀牌價改由 [goldlegend.com 黃金存摺頁](https://www.goldlegend.com/bankbook/bot) 轉載取得。
- 銀樓牌價取自 [goldlegend.com 今日金價](https://www.goldlegend.com/tw/price)（參考牌價，實際以各銀樓公告為準）。

由 GitHub Actions 定時執行（`.github/workflows/update.yml`），排程可能延遲數分鐘到十幾分鐘。
抓到的資料存在 `data/*.csv`，並自動 commit 回 repo。

## 傳給長輩（LINE）

請傳這個連結，LINE 會直接用手機的瀏覽器打開（LINE 內建瀏覽器無法加到主畫面）：

```
https://nmymdf.github.io/gold/?openExternalBrowser=1
```

打開後會自動詢問「把黃金價格放到手機主畫面」：
- **Android（Chrome）**：按「好，加入」→ 系統視窗按「安裝」，主畫面就會出現金色圖示
- **iPhone（Safari）**：依畫面大字步驟：分享 → 加入主畫面 → 新增

手機系統規定一定要使用者按一下確認，網頁無法自己偷偷加圖示。按「以後再說」的話三天內不會再問，右上角的「＋ 主畫面」按鈕隨時可以再按。

## 單位

- 1 錢 = 3.75 公克，1 兩 = 10 錢 = 37.5 公克
- 「賣出」＝店家賣給你（你買入的價格）；「買進」＝店家向你收購（你賣出的價格）

## 開啟 GitHub Pages

Settings → Pages → Source 選 **Deploy from a branch**，Branch 選這個分支、資料夾選 `/ (root)`，存檔後約一分鐘就能開啟：
`https://nmymdf.github.io/gold/`

## 在本機測試

```bash
python3 scripts/fetch.py      # 抓一次最新價格
python3 -m http.server 8000   # 打開 http://localhost:8000
```
